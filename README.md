# AuNews — পুরো প্রজেক্ট (Firebase ছাড়া) 

বাংলাদেশ ও বিশ্বের সব খবর, নিজে নিজে আপডেট হয়। ফ্রি স্ট্যাক: GitHub Actions + GitHub রিপো (ডেটা রাখার জায়গা) + Vercel। কোনো Firebase, কোনো কার্ড লাগে না। (ঐচ্ছিক: ম্যাচ দেখাতে ফ্রি API key — নিচে "নিচের মেনু" অংশ।)

## কীভাবে চলে
1. GitHub Actions প্রতি ৩০ মিনিটে RSS ফিড আনে, ক্যাটাগরি ঠিক করে, একই ঘটনার খবর গ্রুপ করে।
2. ফলাফল রিপোর `data` ব্রাঞ্চে JSON ফাইল হিসেবে রাখে (প্রতিবার একটিমাত্র কমিট, তাই রিপো ভারী হয় না)।
3. Vercel এর সাইট ওই ফাইল পড়ে দেখায় (প্রতি ১০ মিনিটে নতুন করে)।
4. **২৪ ঘণ্টার** পুরনো খবর নিজে বাদ যায় (প্রতিটি পোস্ট নিজের ২৪ ঘণ্টা পূর্ণ হলেই; একসাথে সব মোছা হয় না, তাই সাইট কখনো খালি হয় না)। পুরনো রাখতে চাইলে `retention.days` বাড়ান

## সেটআপ (ক্রমানুযায়ী)
1. এই জিপের ফাইল রিপোতে আপলোড করুন (একই নামের ফাইল ওভাররাইট হবে)।
2. GitHub → Actions → **Ingest news** → Run workflow। সবুজ টিক এলে রানের Summary তে নতুন খবরের সংখ্যা দেখাবে। এতে রিপোতে `data` নামে একটি নতুন ব্রাঞ্চ তৈরি হবে।
3. Vercel → AuNews প্রজেক্ট → Settings → Environment Variables:
   - পুরনো `FIREBASE_SERVICE_ACCOUNT_JSON` থাকলে মুছে দিন।
   - (ঐচ্ছিক) `DATA_REPO` = `আপনার-ইউজারনেম/AuNews`। না দিলে Vercel নিজের Git তথ্য থেকে নেয়।
   - রিপো **Private** হলে: `DATA_GITHUB_TOKEN` লাগবে (নিচে দেখুন)। Public হলে কিছু লাগবে না।
4. Vercel → Deployments → সর্বশেষ ডেপ্লয়ের ⋯ → **Redeploy**।
5. সাইট খুলে দেখুন। না এলে ১০ মিনিট পর রিলোড করুন।

### রিপো Private হলে টোকেন
GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token: Repository access = শুধু AuNews, Permissions → Contents = **Read-only**। টোকেনটি Vercel এ `DATA_GITHUB_TOKEN` নামে বসান।

## এআই ব্রিফ (নতুন) — সাইট নিজে নতুন তথ্য গুছিয়ে পোস্ট করে
`GROQ_API_KEY` থাকলেই চালু। প্রতি ৩০ মিনিটের ইনজেস্টের শেষে:
1. যে ঘটনা **৩টি বা বেশি আলাদা সোর্সে** গত ২৪ ঘণ্টায় এসেছে (গ্রুপিং আগের মতোই), সেটি প্রার্থী হয়।
2. সেই সোর্সগুলোর পেজ থেকে লেখা এনে (সর্বোচ্চ ৩টি, প্রতিটি থেকে ১৪০০ অক্ষর) এআই-কে দেওয়া হয়। কমপক্ষে ২টি সোর্সের লেখা না পেলে ব্রিফ বানানো হয় না।
3. এআই নিজের ভাষায় বাংলায় লেখে: শিরোনাম, ভূমিকা, ৩–৫টি মূল তথ্য (প্রতিটির পাশে সোর্স নম্বর), প্রয়োজনে পটভূমি ও "সূত্রে অমিল"।
4. **যাচাই** (ব্যর্থ হলে প্রকাশ হয় না): সোর্সে নেই এমন সংখ্যা থাকলে বাদ; সোর্স নম্বরহীন পয়েন্ট বাদ; সোর্স থেকে হুবহু অনুলিপি বাদ; বাংলা নয় এমন লেখা বাদ।
5. ফল যায় `data` ব্রাঞ্চের `feeds/digest.json` এ। সাইটে দেখা যায় নিচের মেনুর "এআই ব্রিফ" (`/ai`) পেজে এবং `/p/<id>` এ। ব্রিফও ২৪ ঘণ্টা পর বাদ যায়।
- রান Summary তে দেখাবে কয়টি ব্রিফ হলো, কয়টি যাচাইয়ে বাতিল (কারণসহ)।
- **সীমা** (`config/settings.json` → `digest`): রান প্রতি ২টি, দিনে ২০টি, দিনে ১,৫০,০০০ টোকেন। এটি অনুবাদের চেয়ে আলাদা মডেল (`openai/gpt-oss-20b`) ব্যবহার করে, কারণ Groq এর সীমা মডেল-ভিত্তিক; তাই অনুবাদের কোটা কমে না। মডেল বদলাতে GitHub → Settings → Variables এ `GROQ_DIGEST_MODEL` দিন (যেমন `llama-3.3-70b-versatile`; এর দৈনিক সীমা ১,০০,০০০ টোকেন, তাই `dailyTokenBudget` কমিয়ে ৮০,০০০ করুন)।
- বন্ধ করতে: `digest.enabled` = `false`।

## নিচের মেনু ও নতুন পেজ (নতুন)
নিচে ৫টি মেনু: **হোম** · **ভিডিও** · **এআই ব্রিফ** · **দ্রুত** · **প্রোফাইল**। হোম এখন শুধু "সর্বশেষ" খবরের তালিকা; উপরের ট্যাব (সর্বশেষ, আজকের ১০, ট্রেন্ডিং, ক্যাটাগরি) শুধু খবরের পেজে দেখায়।

### ভিডিও (`/video`)
- ইউটিউব চ্যানেলের RSS থেকে আসে (key লাগে না), প্রতি ৩০ মিনিটে ingest এর সঙ্গে হালনাগাদ; ডেটা `data` ব্রাঞ্চের `feeds/videos.json` এ। ছবিতে ট্যাপ করলে ইউটিউবের প্রাইভেসি-মোড এমবেডে চলে। ২৪ ঘণ্টার পুরনো ভিডিও বাদ।
- চ্যানেল যোগ/বাদ: `config/video.json`। প্রতিটির `handles` (একাধিক দিলে ক্রমে চেষ্টা হয়) বা সরাসরি `channelId` ("UC..." দিয়ে শুরু) দিন, আর `match` এ চ্যানেলের নামের regex — নাম না মিললে ভুল চ্যানেলের ভিডিও ঢোকে না।
- **প্রথম রানের পর** Actions → Ingest → Summary তে "ভিডিও:" লাইন দেখুন: কোন চ্যানেল মিলল, কোনটি মেলেনি (কারণসহ)। যেগুলো মেলেনি সেগুলোর ঠিক handle ইউটিউবে চ্যানেল খুলে URL থেকে (`youtube.com/@নাম`) নিয়ে বসান।
- বন্ধ করতে `enabled: false`। এই পেজ `noindex`।

### দ্রুত (`/quick`)
- **আবহাওয়া** (Open-Meteo, key লাগে না), **সূর্যোদয়/সূর্যাস্ত** ও **নামাজের সময়** — সবই ব্যবহারকারীর নিজের এলাকা ধরে (প্রোফাইলে ৬৪ জেলার তালিকা বা "আমার অবস্থান"; ডিফল্ট ঢাকা)। নামাজ/সূর্যের সময় ডিভাইসেই হিসাব হয় (করাচি পদ্ধতি, হানাফি আসর); স্থানীয় মসজিদের সময়ের সঙ্গে ১–২ মিনিট অমিল হতে পারে।
- **ডলারের দাম** (ExchangeRate-API)। নিচে "Rates By Exchange Rate API" লিংক থাকা তাদের শর্ত; সরাবেন না।
- **ক্রিকেট ও ফুটবল**: চলমান খেলা, আজকের ফলাফল (ঢাকার তারিখ ধরে), আসন্ন ম্যাচ। ডেটার জন্য Vercel → Environment Variables এ ফ্রি key দিন: `FOOTBALL_DATA_KEY` (football-data.org) ও `CRICAPI_KEY` (cricketdata.org; ফ্রিতে দিনে ১০০ কল, ২০ মিনিটের ক্যাশে চলে)। key না দিলে `config/matches.json` এ হাতে ম্যাচ বসানো যায়। কোন লিগ/দল দেখাবে: `config/settings.json` → `matches`।
- Open-Meteo **শুধু অবাণিজ্যিক** ব্যবহারে ফ্রি। সাইটে বিজ্ঞাপন/বিক্রি যোগ করলে `info.weather.enabled` = `false` করুন বা তাদের পেইড প্ল্যান নিন। এই পেজ `noindex`।

### প্রোফাইল (`/profile`)
- লগইন লাগে না। এখানে এলাকা (৬৪ জেলা বা "আমার অবস্থান") ও "দ্রুত পেজে কী দেখবেন" (আবহাওয়া / সূর্যোদয়-সূর্যাস্ত / নামাজ / ডলার / ফুটবল / ক্রিকেট — প্রতিটি আলাদা চালু-বন্ধ) ঠিক করা যায়। সেটিং ওই ডিভাইসের ব্রাউজারেই সেভ থাকে। এই পেজ `noindex`।

## নতুন সোর্স যোগ (ওয়েবসাইট / ফেসবুক)
- **যেকোনো ওয়েবসাইট**: `config/sources.json` এ আরেকটি RSS ফিড বসান (`id`, `name`, `scope`, `lang`, `category`, `url`)। তারপর Actions → Validate feeds চালিয়ে দেখুন ফিডটি কাজ করছে কিনা।
- **ফেসবুক পেজ**: ফেসবুক স্ক্র্যাপিং তাদের নীতির বিরুদ্ধে এবং দ্রুত ব্লক হয়, তাই এতে স্ক্র্যাপার নেই। দুটি বৈধ পথ: (ক) পেজটির নিজস্ব ওয়েবসাইটের RSS (বেশিরভাগ নিউজ পেজের পোস্ট ওয়েবসাইটেও থাকে); (খ) তৃতীয় পক্ষের ফিড-ব্রিজ সার্ভিস (যেমন rss.app) যে পেজের RSS URL দেয়, সেটি এখানে সাধারণ সোর্স হিসেবে বসানো। এসব সার্ভিসের ফ্রি সীমা ও শর্ত তাদের সাইটে দেখে নিন।
- **অ্যাপ**: মোবাইল অ্যাপের ভেতরের ডেটা বাইরে থেকে পড়ার বৈধ উপায় নেই। অ্যাপটির ওয়েব সংস্করণে RSS থাকলে সেটিই সোর্স।

## আজকের বড় খবর (নতুন)
প্রতিদিন ঢাকার সময় সকাল ৭টার পর প্রথম রানে একবার তৈরি হয়; সাইটে উপরের "আজকের ১০" ট্যাবে (`/daily`) দেখা যায়।
- বাছাই: গত ২৪ ঘণ্টায় যে ঘটনা সবচেয়ে বেশি আলাদা সোর্সে এসেছে (কমপক্ষে ২টি), সর্বোচ্চ ১০টি; এর মধ্যে বিশ্ব-খবর সর্বোচ্চ ৪টি।
- **এআই লাগে না**, তাই কোনো তথ্য বানানোর ঝুঁকি নেই। ঘটনাটির এআই ব্রিফ থাকলে তার শিরোনাম ও ভূমিকা দেখায়; না থাকলে সোর্সের বাংলা শিরোনাম ও মূল লিংক। বাংলা শিরোনাম নেই এমন ঘটনা বাদ।
- ৩টির কম ঘটনা পেলে সেদিন তৈরি হয় না (পরের রানে আবার চেষ্টা)। সেটিং: `config/settings.json` → `daily`।
- ২৪ ঘণ্টা রিটেনশনের কারণে শুধু সর্বশেষ সংস্করণটি থাকে (`daily.keep: 1`; আগের দিনের তালিকা রাখতে সংখ্যা বাড়ান)। ব্রিফ মুছে গেলে তালিকার লিংক মূল সোর্সে যায়, তাই ভাঙা লিংক থাকে না। এই পেজগুলো `noindex`, কারণ এগুলো অন্য সাইটের শিরোনামের তালিকা; ভেতরের এআই ব্রিফগুলো নিজেদের পেজে ইনডেক্স হয়।

## টেলিগ্রাম চ্যানেলে অটো-পোস্ট (নতুন)
চ্যানেলে যায়: (১) সকালে "আজকের বড় খবর", (২) নতুন এআই ব্রিফ (৬ ঘণ্টার মধ্যে তৈরি হলে; রান প্রতি সর্বোচ্চ ৩টি, দিনে মোট ২৫টি)। রাউন্ডআপে থাকা ব্রিফ আলাদা করে আবার যায় না।
সেটআপ:
1. টেলিগ্রামে **@BotFather** → `/newbot` → নাম ও username দিন (শেষে `bot` থাকতে হবে)। যে **টোকেন** দেবে সেটি কাউকে দেখাবেন না।
2. একটি **পাবলিক চ্যানেল** খুলুন, username দিন (যেমন `@aunews_bd`)।
3. চ্যানেল → Administrators → Add Administrator → আপনার বট → **Post messages** অনুমতি দিন।
4. GitHub রিপো → Settings → Secrets and variables → Actions:
   - **Secrets** এ `TELEGRAM_BOT_TOKEN` = বটের টোকেন
   - **Variables** এ `TELEGRAM_CHAT_ID` = `@aunews_bd` (আপনার চ্যানেলের username)
5. **আগে ড্রাই-রান**: Variables এ `TELEGRAM_DRY_RUN` = `1` দিয়ে Actions → Ingest news → Run workflow। Summary তে বার্তাগুলো কেমন হবে দেখা যাবে, কিছু পাঠানো হবে না। ঠিক লাগলে ওই ভ্যারিয়েবলটি মুছে দিন; তখন থেকে সত্যিকারের পোস্ট শুরু।
- রান Summary তে "টেলিগ্রাম" লাইনে ফল ও ত্রুটি দেখাবে (বট অ্যাডমিন না হলে, চ্যানেল না মিললে ইত্যাদি)। এমন ত্রুটিতে ৬ ঘণ্টা বিরতি দিয়ে আবার চেষ্টা করে।
- টোকেন ফাঁস হলে BotFather → `/revoke`, নতুন টোকেন Secrets এ বসান।
- বন্ধ করতে: `telegram.enabled` = `false` বা Secret মুছুন। সেটিং: `config/settings.json` → `telegram`।
- সাইটের ঠিকানা বদলালে Variables এ `SITE_URL` দিন (না দিলে `settings.json` এর `site.url`)।

## ফেসবুক পেজে অটো-পোস্ট (নতুন)
প্রতি **৬০ মিনিটে একটি** ছবি-পোস্ট যায়। ছবিটি নিউজ-কার্ডের মতো: ওপরে খবরের ছবি, নিচে লাল ব্যান্ডে **শিরোনাম** (সঙ্গে তারিখ ও ব্র্যান্ড); **মূল লেখা** (ভূমিকা, ৩টি তথ্য, সোর্স সংখ্যা, লিংক) ক্যাপশনে।
- কোন খবর যায়: সবচেয়ে নতুন **এআই ব্রিফ** (১২ ঘণ্টার মধ্যে)। নতুন ব্রিফ না থাকলে একাধিক সোর্সে আসা, ছবি ও বাংলা শিরোনামসহ সাধারণ খবর (ক্যাপশনে সোর্সের নাম ও মূল লিংক)। এটি বন্ধ করতে `facebook.fallbackToNews` = `false`।
- সময়: ওয়ার্কফ্লো প্রতি ৩০ মিনিটে চলে; প্রতি ঘণ্টার স্লটে একটিই পোস্ট যায়। কোনো রান ব্যর্থ হলে একই ঘণ্টার পরের রানে আবার চেষ্টা হয়, তাই সময় সরে সরে যায় না।
- একই ঘটনা দুবার যায় না (ব্রিফ হয়ে গেলে ওই ঘটনার সাধারণ খবর আর যায় না)। দিনে সর্বোচ্চ ৩০টি।
- ছবি না পেলে বা ছোট হলে ব্র্যান্ডেড ব্যাকগ্রাউন্ডে কার্ড হয়।
সেটআপ:
1. GitHub রিপো → Settings → Secrets and variables → Actions:
   - **Secrets** এ `FACEBOOK_PAGE_TOKEN` = **Page Access Token** (ইউজার টোকেন নয়; অনুমতি: `pages_manage_posts`, `pages_read_engagement`)
   - **Variables** এ `FACEBOOK_PAGE_ID` = পেজের আইডি (সংখ্যা)
2. **আগে ড্রাই-রান**: Variables এ `FACEBOOK_DRY_RUN` = `1` দিয়ে Actions → Ingest news → Run workflow। কিছু পোস্ট হয় না; রানের শেষে **Artifacts → facebook-preview** এ কার্ডের ছবি (`facebook-card-1.jpg`) ও ক্যাপশন (`facebook-caption-1.txt`) নামিয়ে দেখুন। ঠিক লাগলে `FACEBOOK_DRY_RUN` মুছে দিন; তখন থেকে সত্যিকারের পোস্ট।
3. রান Summary তে "ফেসবুক" লাইনে ফল ও ত্রুটি দেখাবে। টোকেন/অনুমতির ত্রুটিতে ৬ ঘণ্টা, রেট-লিমিটে ৩০ মিনিট বিরতি দিয়ে আবার চেষ্টা করে।
- টোকেন: **long-lived Page token** নিন (User token → long-lived → `me/accounts` থেকে Page token; এটি সাধারণত মেয়াদ-হীন)। কার্ড ঠিক না লাগলে বা পোস্ট না গেলে Summary র ত্রুটিটি দেখুন (যেমন `#190` = টোকেন অচল, `#200` = অনুমতি নেই)।
- বাংলা ফন্ট: ওয়ার্কফ্লো নিজে `fonts-noto-core` (Noto Sans Bengali) ইনস্টল করে; কার্ডের ছবি আঁকে `sharp` দিয়ে।
- Graph API ভার্সন: ডিফল্ট `v25.0`; বদলাতে Variables এ `FACEBOOK_API_VERSION` (যেমন `v26.0`)।
- বন্ধ করতে: `facebook.enabled` = `false` বা Secret মুছুন। সেটিং: `config/settings.json` → `facebook`।
- সতর্কতা: খবরের ছবি ও শিরোনাম অন্য সংবাদমাধ্যমের হতে পারে; পেজে সেগুলো দিলে কপিরাইট অভিযোগ আসতে পারে। ক্যাপশনে সোর্সের লিংক থাকে।

## গুগলে আনা (Search Console)
কোড দিকটা তৈরি: `sitemap.xml`, `robots.txt`, শেয়ার-প্রিভিউ ট্যাগ, `canonical`, ব্রিফে NewsArticle ডেটা, `/about`, `/feed.xml`। আপনাকে শুধু যাচাই করাতে হবে:
1. search.google.com/search-console → **Add property** → **URL prefix** → `https://aunews.vercel.app`
2. যাচাইয়ের পদ্ধতি **HTML tag** বেছে `content="..."` এর ভেতরের কোডটি কপি করুন।
3. Vercel → Project → Settings → Environment Variables → নাম `GOOGLE_SITE_VERIFICATION`, মান ওই কোড → Save → **Redeploy** → Search Console এ Verify।
4. Search Console → **Sitemaps** → `sitemap.xml` জমা দিন।
5. **URL inspection** এ হোম পেজ ও একটি `/p/…` ব্রিফের লিংক দিয়ে "Request indexing"।
- Bing: Bing Webmaster Tools এ একইভাবে; কোডটি `BING_SITE_VERIFICATION` নামে দিন।
- `config/settings.json` → `site.contact` এ আপনার ইমেইল, `site.social` এ ফেসবুক/টেলিগ্রাম লিংক দিন; `/about` এ দেখাবে।
- কাস্টম ডোমেইন নিলে Vercel এ `NEXT_PUBLIC_SITE_URL` দিন এবং পুরনো ঠিকানা থেকে নতুনে redirect রাখুন।
- ইচ্ছা করে noindex রাখা: `/n/*` (অন্যের পুরো লেখা), ক্যাটাগরি, ট্রেন্ডিং, সার্চ। কারণ এগুলো অন্য সাইটের লেখার তালিকা। মৌলিক লেখা বাড়লে ক্যাটাগরি পেজের `robots` সরিয়ে দিন।

## সমস্যা হলে
- **Ingest এর শেষ ধাপে `403` / permission ত্রুটি:** রিপো → Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save। তারপর আবার চালান।
- **সাইটে খালি:** আগে Ingest সবুজ কিনা দেখুন; তারপর রিপোতে `data` ব্রাঞ্চ আছে কিনা (Code পেজে ব্রাঞ্চ ড্রপডাউন); তারপর Vercel এ Redeploy।
- **Vercel এ `data` ব্রাঞ্চের জন্য বারবার বিল্ড:** `vercel.json` এ বন্ধ করা আছে; তবু হলে Vercel → Settings → Git এ দেখুন।
- পাবলিক রিপোতে ৬০ দিন কোনো কার্যকলাপ না থাকলে GitHub শিডিউল বন্ধ করে দিতে পারে; Actions ট্যাব থেকে আবার চালু করুন।

## সেটিংস (`config/settings.json`)
- `site.name`: অ্যাপের নাম (AuNews)।
- `retention`: `days: 1`; `mode: "rolling"` (প্রতিটি খবর ২৪ ঘণ্টা পর বাদ) বা `"weekly_wipe"` (প্রতি `days` দিনে সব একসাথে — সাইট হঠাৎ খালি হয়, তাই ২৪ ঘণ্টার জন্য `rolling`ই ভালো)। ভিডিও ও এআই ব্রিফও এই সময় মানে।
- `ingest.windowDays: 3`: ইনজেস্টের সর্বোচ্চ সময়সীমা; আসলে `retention.days` এর চেয়ে বেশি পেছনে যায় না (এখন ২৪ ঘণ্টা)।
- `cluster.threshold: 0.45`: একই খবর গ্রুপ করার সংবেদনশীলতা।
- `snapshot`: ফিডে কয়টি খবর রাখা হবে (ক্যাটাগরি প্রতি ৮০, সর্বশেষ ৪০০; হোমে সর্বশেষ ১৫০টি দেখায়, বাকিটা ট্রেন্ডিং-এর জন্য)।
- `cluster.trendingMinSources: 2`: ট্রেন্ডিং-এ আসতে কমপক্ষে কয়টি আলাদা সোর্সে খবরটি আসতে হবে।
- `digest.*`: এআই ব্রিফের সীমা ও শর্ত (`minSources`, `maxPerRun`, `dailyMax`, `dailyTokenBudget`, `keep` ইত্যাদি)।
- `info.*`: "দ্রুত" পেজের আবহাওয়া ও ডলার (চালু/বন্ধ)।
- `matches.*`: ম্যাচ কার্ড (কোন ফুটবল লিগ, কোন ক্রিকেট দল, সর্বোচ্চ কয়টি)। `config/video.json`: ভিডিও চ্যানেল।
- `daily.*`: আজকের বড় খবর (`hourDhaka`, `maxStories`, `minSources`, `maxWorld`, `keep: 1`)।
- `telegram.*`: টেলিগ্রাম পোস্টের সীমা (`maxAgeHours`, `maxPerRun`, `dailyMax`)।
- `facebook.*`: ফেসবুক পোস্ট (`intervalMinutes: 60`, `maxAgeHours`, `dailyMax`, `fallbackToNews`, `newsMinSources`, `hashtags`, `apiVersion`)।
